# Homebrew tap for fleetreach

```sh
brew install tess-fun/tap/fleetreach
```

[fleetreach](https://github.com/tess-fun/fleetreach) is a fleet-wide dependency security
auditor. The formula installs the prebuilt, checksummed release binary for macOS (Apple
silicon and Intel) and Linux (x86-64 and ARM64). It is updated automatically by the
fleetreach release workflow; please open issues in the main repository.
